# v0.1.0 发布说明

Clash Sentinel 首个终端运行版，面向 macOS 上的 Clash Verge Rev / Mihomo。

## 功能

- 本机 Web 看板展示连接、站点、入口、候选 IP、任务和事件。
- 定时健康检测、手动诊断与入口 IP 切换、失败恢复及自动切换安全保护。
- SSE 实时更新，断线后低频刷新并在重连时重新同步。
- `npm run dev` 用于开发；`npm run build && npm start` 用于终端运行。

## 已知限制

- 仅支持 macOS、当前选中的 Clash Verge Rev 订阅和同一入口域名的 IPv4 候选。
- 没有安装器、登录自启动、菜单栏应用或远程访问。
- Clash 配置或控制接口不可用时页面降级可用，相关检测与配置动作无法完成。
- 使用 GitHub 源码包时须安装 Node.js 24、运行 `npm ci` 和 `npm run build`；不会包含数据库、报告、备份或本机配置。
